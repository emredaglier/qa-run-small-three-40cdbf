Allowed. The command only reads files (find, echo, grep). It searches the Next.js docs in your own worktree's `apps/web/node_modules`. The checker flagged `$f` only because it can't resolve a shell variable, not because the path leaves the project. To avoid the next hold, run `find` first, then `grep` the literal path it prints. Run both from the worktree root, without `cd`.
