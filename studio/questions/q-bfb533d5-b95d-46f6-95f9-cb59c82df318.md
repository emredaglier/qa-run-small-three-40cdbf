Denied as written: `npx` can download a Prettier the lockfile doesn't pin. Prettier is already a root devDependency (`3.9.9`, in `pnpm-lock.yaml`), so run the pinned one: `pnpm exec prettier --write apps/web/src/app/internal/revalidate/route.ts perf/scenarios.ts`, then your `git diff … | grep "^[+-]"` and `pnpm lint`. If `pnpm exec` can't find it, run `pnpm install` first. Don't add or bump anything.
