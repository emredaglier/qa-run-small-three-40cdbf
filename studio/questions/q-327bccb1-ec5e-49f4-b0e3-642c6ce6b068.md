Allowed. This loop runs the required proof-of-work checks (lint, typecheck, test, check:assets) inside your ticket worktree. `${PIPESTATUS[0]}` is a shell variable, not a path outside the project. One thing to watch: in zsh, `PIPESTATUS` is empty (zsh uses lowercase `pipestatus`, which starts at index 1). If an exit code comes back blank, run each check on its own and report its real exit code. Don't guess it from the tail.
